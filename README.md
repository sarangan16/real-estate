
Real Estate is a modern web application for browsing and exploring real estate listings. It is built with React, Vite, and Tailwind CSS, offering a fast, responsive, and interactive user experience. The project incorporates animations with Framer Motion and notifications using React Toastify.

## Features

- Browse real estate listings
- View detailed property information
- Interactive and smooth animations powered by Framer Motion
- Toast notifications for user interactions and updates
- Responsive design for desktop and mobile devices
- Optimized frontend using Vite for fast development and build times

## Technology Stack

- Frontend: React, Vite, Tailwind CSS, Framer Motion, Lucide React, React Toastify
- Development Tools: ESLint, ESLint Plugins, Vite
